# A line: message | checks. "\n" in a message is a new line. Checks are separated by ";":
#   expense 50 / income 25000 / transfer 1000   item 1's type and amount

#   2:wallet=เงินสด   (a check on item 2)
#   desc=กินบุฟเฟต์   date!=today   ("!=" = must not be)
#   kind=saving|debt|create  action=save|allocate|move|withdraw  goal=<name>|spare  from=<name>|-
#   event=<name>|-  newevent=<name>|-  people=2  payer=me|<name>  side=they_owe_me|i_owe_them|they_repay|i_repay
#   money=true|false  person=<name>|-  recurring=<name>|-   (the new kinds; hint=goal_missing | event_done too)
